Evolução dos escudos

Cada linha representa um clube. Ela fica mais espessa quanto mais tempo o desenho atual do escudo está em uso; ao trocar de desenho, a linha volta a ficar fina. Se um desenho antigo voltar a ser usado, a linha retoma a espessura que tinha quando ele foi abandonado.

quanto mais espessa, mais tempo o desenho está em uso
troca de desenho reinicia a espessura
📝 Editável: escudos-dados.csv ✏️ clique no arquivo no GitHub para editar
Os dados estão no arquivo escudos-dados.csv. Para editar, clique no arquivo no GitHub e use o ícone de lápis (✏️). Depois de salvar, recarregue esta página.
Estrutura: cada linha é um período de um desenho de escudo. Deixe "Fim" vazio se o desenho ainda está em uso hoje.
